# QuickAnswer

دکمهٔ شناور روی صفحه که سؤال ۴گزینه‌ای را از روی تصویر صفحه تشخیص می‌دهد و دور گزینهٔ درست یک کادر سبز می‌کشد (متن گزینه هم روی دکمه نوشته می‌شود).
برای بازی‌ها و مسابقه‌های پرسش‌وپاسخ و تمرین شخصی طراحی شده است.

## دریافت APK بدون Android Studio (GitHub Actions)
1. در github.com یک حساب و یک مخزن (repository) جدید بسازید.
2. محتویات همین پوشه (از جمله پوشهٔ مخفی `.github`) را در مخزن آپلود کنید.
3. تب Actions ← «Build APK» ← بعد از پایان ساخت (چند دقیقه)، فایل `QuickAnswer-apk` را از بخش Artifacts دانلود کنید.
4. zip را باز کنید و `app-debug.apk` را روی گوشی نصب کنید (نصب از منبع ناشناس را مجاز کنید).

## ساخت با Android Studio
1. پوشه را در Android Studio (نسخهٔ Koala یا جدیدتر) باز کنید؛ Gradle wrapper را خودش می‌سازد.
2. گوشی را با USB وصل کنید و Run بزنید.
3. در برنامه کلید API را وارد کنید و «شروع» را بزنید.
4. مجوز «نمایش روی برنامه‌های دیگر» و مجوز ضبط صفحه را تأیید کنید.

## استفاده
- لمس کوتاه دکمه: تشخیص همین لحظه
- لمس طولانی: حالت خودکار (وقتی صفحه روی یک سؤال جدید ثابت شد، خودش جواب می‌دهد)
- کشیدن: جابه‌جایی دکمه
- «توقف» در برنامه: پایان سرویس

## سرعت
- تصویر با رزولوشن پایین گرفته و فشرده می‌شود (۷۲۰ پیکسل، JPEG).
- آخرین فریم همیشه آماده است، پس لمس بدون تأخیر ضبط ارسال می‌شود.
- مدل پیش‌فرض `claude-haiku-5-5` است (سریع‌ترین)؛ در `Solver.kt` قابل تغییر است.
- بیشترین زمان مربوط به شبکه و مدل است؛ اینترنت پایدار مهم است.

## نکته‌ها
- کلید API فقط روی خود گوشی ذخیره می‌شود. برای انتشار عمومی از سرور واسط استفاده کنید.
- در بعضی بازی‌ها ضبط صفحه مسدود است (FLAG_SECURE)؛ آنجا تصویر سیاه می‌آید.
- فقط برای بازی و یادگیری استفاده کنید، نه آزمون‌های رسمی یا رقابتی که قوانینش اجازه نمی‌دهد.
